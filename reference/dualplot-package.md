# dualplot: Unified Plotting Primitives for Base Graphics and ggplot2

Provides a unified, lightweight set of plotting primitives that render
consistent visualizations across both base R 'graphics' and 'ggplot2'
backends, with seamless color theme integration via 'colortheme'.
